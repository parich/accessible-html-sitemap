# Checklist ทดสอบการเข้าถึง (WCAG 2.1 AA) ด้วยตนเอง

`npm run test:a11y` (axe-core) ตรวจได้เฉพาะสิ่งที่อ่านจาก HTML ได้ ส่วนข้างล่างนี้ต้องทดสอบในเบราว์เซอร์จริงบน theme ที่ใช้งาน

**วิธีเตรียม:** สร้างหน้าทดสอบที่มี `[parich_sitemap]` (หรือ block Parich Accessible Sitemap) บนเว็บที่มีเนื้อหาจริง แล้วเปิดด้วย Chrome หรือ Firefox บน Windows

| # | เกณฑ์ | วิธีทดสอบ | ผลที่ต้องได้ | ผล |
|---|---|---|---|---|
| 1 | 2.1.1 Keyboard | กด Tab ไล่ตั้งแต่ต้นจนจบ sitemap | ไปถึงทุกลิงก์ได้ ตามลำดับที่เห็นบนจอ ไม่ติดค้างที่ใด | |
| 2 | 2.4.7 Focus Visible | ดูลิงก์ที่ได้ focus ขณะกด Tab | มีกรอบ focus เห็นชัดทุกลิงก์ (theme ต้องไม่ซ่อน) | |
| 3 | 2.4.1 Bypass Blocks | กด Enter ที่ลิงก์ในสารบัญ "On this page" แล้วกด Tab ต่อ | จอเลื่อนไปที่หัวข้อนั้น และ Tab ถัดไปคือลิงก์แรกของหัวข้อนั้น | |
| 4 | 1.3.1 / 2.4.6 | NVDA: กด Insert+F7 ดูรายการ Landmarks และ Headings | มี landmark "navigation แผนผังเว็บไซต์" และหัวข้อ section ครบ ระดับหัวข้อต่อจากหัวข้อของหน้า | |
| 5 | 1.3.1 Lists | NVDA: เลื่อนเข้า list ด้วยปุ่ม L | อ่านจำนวนรายการและระดับ list ซ้อน (หมวด → หมวดย่อย → โพสต์) ได้ถูก | |
| 6 | 4.1.2 aria-current | เปิดหน้าหรือโพสต์ที่มีอยู่ใน sitemap (ถ้ามี sitemap ในหน้านั้น) หรือเปิดหน้า sitemap เอง | NVDA อ่านลิงก์ของหน้าปัจจุบันว่า "current page" | |
| 7 | 1.4.3 Contrast | ตรวจสีลิงก์และข้อความกับพื้นหลังด้วย DevTools หรือ WebAIM Contrast Checker | อย่างน้อย 4.5:1 (ขึ้นกับ theme ปลั๊กอินไม่กำหนดสี) | |
| 8 | 1.4.11 Non-text Contrast | ตรวจสีกรอบ focus กับพื้นหลัง | อย่างน้อย 3:1 | |
| 9 | 1.4.4 Resize Text | ซูมเบราว์เซอร์ 200% | อ่านได้ครบ ข้อความไม่ทับหรือถูกตัด | |
| 10 | 1.4.10 Reflow | DevTools โหมดมือถือ กว้าง 320px — markup ของปลั๊กอินตรวจอัตโนมัติแล้วด้วย `npm run test:reflow` ข้อนี้จึงตรวจเพิ่มแค่ว่า theme ไม่ทำให้ล้น | ไม่มี scroll แนวนอน ชื่อยาว ๆ (รวมภาษาไทยที่ไม่มีช่องว่าง) ขึ้นบรรทัดใหม่ได้ | |
| 10b | 2.1.1 / 4.1.2 พับ/ขยาย | ถ้าเปิด `collapsible`: Tab ไปที่ชื่อหมวด กด Enter หรือ Space | หมวดพับ/ขยายได้ และ NVDA อ่าน "ขยาย" / "ยุบ" | |
| 11 | 1.4.12 Text Spacing | ใช้ bookmarklet Text Spacing (line-height 1.5, letter-spacing 0.12em, word-spacing 0.16em, paragraph 2em) | ข้อความไม่ถูกตัดหรือซ้อนทับ | |
| 12 | 3.1.1 / 3.1.2 Language | ดู `lang` ของหน้า (DevTools) | ตรงกับภาษาของเนื้อหา (`th` สำหรับเว็บภาษาไทย) — ขึ้นกับ theme | |
| 13 | 2.4.1 กลับไปสารบัญ | Tab ไปจนสุดส่วนหนึ่ง แล้วกด Enter ที่ "Back to contents" / "กลับไปที่สารบัญ" แล้วกด Tab ต่อ | จอกลับไปที่สารบัญ และ Tab ถัดไปคือลิงก์แรกของสารบัญ | |
| 14 | 1.4.11 โหมดคอนทราสต์สูง | Windows: Settings → Accessibility → Contrast themes เลือกธีมใดก็ได้ แล้วเปิดหน้า sitemap — ปลั๊กอินตรวจอัตโนมัติแล้วด้วย `npm run test:media` ข้อนี้ดูกับ theme จริง | ข้อความ ลิงก์ กรอบ focus และเส้นต้นไม้เห็นชัดในสีของธีม (เส้นเข้มเต็มที่) | |
| 15 | การพิมพ์ (ไม่ใช่เกณฑ์ WCAG) | เปิด `collapsible="closed"` แล้วกด Ctrl+P ดูตัวอย่างก่อนพิมพ์ใน Firefox / Safari — Edge/Chrome ตรวจอัตโนมัติแล้วด้วย `npm run test:media` | ไม่มีสารบัญและลิงก์กลับ, หมวดที่พับไว้ถูกกางครบ (browser ที่ยังไม่รองรับ `::details-content` จะพิมพ์เฉพาะหมวดที่กางอยู่) | |
